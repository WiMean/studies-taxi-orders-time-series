# Прогнозирование заказов такси (временные ряды)

**Задача.** Сервис такси собирает исторические данные о заказах. Нужно спрогнозировать количество заказов на следующий час, чтобы привлекать больше водителей в часы пик. RMSE не выше 48.

**Что сделано.** Ресемплирование данных по часам, анализ тренда и сезонности, генерация лаговых признаков и скользящих статистик, обучение и сравнение моделей, анализ важности признаков.

**Стек.** Python, pandas, statsmodels, scikit-learn, CatBoost, LightGBM, SHAP

**Результат.** RMSE 32,4 при пороге 48

**Ноутбуки:**

- `taxi-orders-time-series.ipynb`
